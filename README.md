# paulsteyn.com

One-page personal site for Paul Steyn. Plain HTML/CSS, no build step — Netlify publishes the repo root.

- `index.html` — the page (copy, SEO meta, JSON-LD structured data)
- `images/` — portrait, hero, stills, share image
- `netlify.toml` — redirect apex → www, cache/security headers
- `robots.txt`, `sitemap.xml`

To update: edit, commit, push. Netlify deploys automatically.
